# Minimal TV

Launcher leve para TCL S5400A (Android TV 11, 0,9 GB RAM).

## Instalar na TV
1. Abra o app **Downloader**.
2. Digite: `is.gd/minimaltv` (atalho para `github.com/eualexmartins2000/minimal-tv/releases/download/latest/minimal-tv.apk`)
3. Instale. Para atualizar, repita (o endereço é sempre o mesmo).

## Como funciona o build
Cada push compila o APK no GitHub Actions e publica na release `latest`.
Layouts de referência em `design/`.
